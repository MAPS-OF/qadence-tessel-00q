# maps-of/qadence-tessel-00q

This repository anchors the official initial phase-space frame for Qadence Tessel's large-island map model.

The starting frame is intentionally a coordinate, not a copy of the full solver database: arrangement 57 is represented by a photographed `10♥️` Where's Waldo card, and its centroid seed family `F-12SLTV5` is represented by a photographed Lord of the Rings Heroes & Villains card whose upright frame reads `9♠️` (the opposite corner reads `6♠️` under a 180° reversal). Neither source deck has been assigned an emoji deck ID, so this chronicle uses their textual names.

`opinionated-set-aquaman.json` records Qadence's chosen mapping from the fifteen AQUAMAN cards to the fifteen current opinionated-set roles. The deal order is preserved in `cards-of/qadence-tessel-00q/WITH/🔱/AS/deck-of/AQUAMAN/casting.json`.

`arrangements/arrangement-057.json` dogfoods the map layer: it cements the
photographed `10♥️` arrangement coordinate and `9♠️` family coordinate, then
records the selected 16×14 board as piece cells plus an orthogonal edge graph.
